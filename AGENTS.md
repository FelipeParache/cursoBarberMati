
# Proyecto: Curso de Barbería Profesional | Matías

## Descripción General

Este proyecto consiste en una landing page para promocionar y vender un curso online de barbería profesional dictado por Matías, un barbero con 9 años de experiencia en Buenos Aires.

## Propósito

El objetivo principal de la landing page es convertir visitantes en clientes, incentivándolos a inscribirse en el curso.

## Stack Tecnológico

*   HTML
*   CSS
*   JavaScript

## Estructura de la Aplicación

*   `index.html`: Estructura principal de la landing page.
*   `styles.css`: Estilos visuales de la landing page.
*   `script.js`: Funciones interactivas de la landing page.
*   `fotos/`: Contiene imágenes del barbero y cortes de pelo.
*   `videos/`: Contiene videos promocionales del curso.

## Convenciones

*   **Estilo de código:** Se utilizarán las convenciones de HTML, CSS y JavaScript estándar.
*   **Nombres de clases CSS:** Se utilizarán nombres descriptivos y consistentes.
*   **Comentarios:** Se agregarán comentarios claros y concisos para explicar el código.
